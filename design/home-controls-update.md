# 首页连接控制更新 / 7.1

此更新在现有精简版上原位执行，不新增页面。默认中文。

历史版本状态：7.1 已在原 RainLink 文件中完成两端更新。桌面开关行位于连接主卡下方、代理模式上方；移动端位于当前分组下方。以下双开关说明仅记录 7.1 历史版本；当前移动端使用“网络接管”授权信息行，最新原生 `.fig` 与核验报告见 `exports/compact-v7.5/`。

运行开发插件 `RainLink Design Studio → 系统代理与 TUN 模式移到首页`。

- 桌面概览连接主卡下方、代理模式上方，使用 56 px 高的双开关行。
- 移动首页：当前分组下方、代理模式上方，使用 52 px 高的双开关行，命中高度 44 px。
- 系统代理、TUN 模式分别开关；连接总开关、规则／全局／直连保持独立。
- 桌面设置删除原来的两个设置项；移动设置保留 DNS 等设置。
- 四种连接状态都复用这行组件。两个独立开关使用四个局部变体，不复制整页。
- 桌面压缩连接卡与图表的留白；移动连接按钮调整至 72 px，保留公网 IP、国旗、速度与今日流量。

源码：`plugin/home-network-controls.js`。重复执行会复用已经创建的组件和首页实例。
源码更改后运行 `python design/update_source.py`；之后的“精简画布与组件交互”维护也会保留此次调整。

核验结果：桌面仍为 12 个画面，移动端仍为 11 个画面；所有产品画面保留 Auto Layout。四种连接状态均在首屏内显示，移动端保留 IP、国家图标、速度和今日流量。两个开关的每端八条独立切换连线已核对，整份原型没有失效目标。原生文件 ZIP CRC 与 `fig-kiwi` 文件头检查通过。网络数据仍为设计示例。
