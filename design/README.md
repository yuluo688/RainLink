## 画布

文档保留三个页签：桌面端、移动端、设计系统与流程。

桌面 8 个主页面：概览、节点、分组、规则、连接、流量、日志、设置。另保留代理链编排和添加、订阅信息、移动节点三个弹窗，共 12 个画面。

移动端 8 个主要画面：首页、节点、分组、流量、设置、快速选择、DNS、代理链编排。另保留添加、订阅信息、移动节点三个弹窗，共 11 个画面。

主要画面按 4 × 2 网格整理。已移除 425 个重复的整页状态稿，节点选择、分组选择、连接开关、检测、添加和代理链测试使用可复用组件变体。

## 使用方式

1. 分组或节点页点击“添加”，在弹窗内选择订阅或单个节点。
2. 订阅只填写 URL。名称采用服务返回值，缺失时用域名或自动编号，更新时跟随服务名称；导入后自动成组。
3. HTTP、SOCKS5 等单节点添加后进入未分组。仅未分组节点显示移动入口。
4. 在分组页点击选中；在节点页选择分组、节点。选择本身不触发连接。
5. 在概览点击“开始连接”或“断开连接”，选择规则、全局或直连模式。桌面端独立控制系统代理和 TUN；移动端显示网络接管授权与连接状态。
6. 订阅条目展示流量、总额度、剩余流量和到期日，信息缺失时明确显示未提供。每个订阅的更多入口只展示当前订阅，提供更新、编辑链接和删除。
7. 代理链在节点工具栏进入；通过跳点上移、下移、更换和移除进行可视化编排，测试后保存并选中。

分组条目只展示组名、节点数量和订阅信息，不展示组内当前节点名与延迟。点选卡片切换分组，点右侧入口进入节点列表。桌面分组统一 72 px，用量、到期时间与操作横向对齐；节点行 56 px，分组间距 8 px。移动端订阅卡 108 px，未分组 66 px，节点卡 72 px，列表间距 8 px；节点名称、协议、地区、延迟和收藏保留在节点列表中。

节点页支持全分组搜索，匹配节点名称、协议和地区，不区分大小写，多个关键词取交集。结果标明所属分组，保留节点选择、收藏与未分组移动入口；清空后恢复分组浏览。桌面搜索框置于现有工具栏，移动端搜索行高 44 px。

原型点击搜索框依次演示“日本”“HTTP”和无结果状态，点击 × 或“清空搜索”恢复列表。Figma 使用示例关键词，实际应用需要实现文本输入、即时筛选和清空后保留原选择。

“个人工作区”和桌面列表右侧重复信息卡已删除。高级 YAML / JSON 配置归入设置。

## 概览出口

概览展示检测得到的公网 IP、矢量国旗、中文国家和检测时间。国家由检测返回的 ISO 国家代码决定，不能由节点标签推断。

未连接时检测直连出口；连接后经当前代理检测；直连模式仍使用直连路径。连接状态、模式或实际出站变化后清空旧结果，先显示检测中。失败显示未获取，国家缺失显示地球图标。规则模式仅说明检测请求的出口。

设计使用 RFC 5737 文档地址及独立国家示例，未采集用户真实 IP。订阅、测速、扫码和流量也属于设计示例。

## 原型与实现边界

弹窗为原生 OVERLAY，取消、完成和遮罩使用 CLOSE；同页状态用 CHANGE_TO 和定时组件切换。主要导航、添加、分组和节点选择、连接开关、模式检测及代理链流程可检查。

精简原型采用本地组件交互，跨页选择为代表性演示，没有模拟应用的全局状态存储。正式产品需共享所选分组、每组节点和实际连接目标，并在连接中改选时提示待应用。

本轮 UI 评估修复的实时核验、截图与原型扫描保存在 `exports/compact-v7.5/review-fixes/`，范围见 `reviews/2026-10-15/修复说明.md`。新增状态继续使用组件变体，未增加产品画面。

最新修复已在 Figma 原位应用。桌面 12、移动 11 个产品画面均已重新导出，三页原型扫描无失效目标或截断；浅色窄屏与首次使用示例也已复核。维护本轮版本使用“修复已知问题”；旧“补全两端设置 UI”和“统一返回箭头至左上角”命令也会保留本轮修复。

连接术语已统一为“开始连接／断开连接”“已连接／未连接”；移动平台能力标为“网络接管”，授权提示与使用说明同步更新。现有组件和画面原位维护，产品画面数量保持不变。

添加弹窗支持八种协议及折叠参数、订阅错误与重试。代理链提供跳点选择、排序、添加、移除、测试失败与“保存并选中”。规则、连接、流量和日志包含代表性操作结果；这些反馈用于验证设计流程，不执行真实网络请求或文件导出。移动端辅助文字与点击区域按 12 px / 44 px 校验，小屏、浅色、大字和键盘场景集中放在设计系统中。

跨页状态由客户端实现共享：`selectedTarget` 保存所选目标，`activeOutbound` 保存实际出站；连接中改选会进入 `pendingApply`，在概览重新开启后应用。示例菜单演示当前节点的操作结构，实际客户端需按节点来源限制编辑和隐藏权限。

所有产品画面使用 Auto Layout。中文使用思源黑体，数字使用 Inter，IP 与代码使用 Roboto Mono；主色为薄荷绿，支持深浅主题颜色变量。

设计依据 awesome-design-md 中 Linear、Vercel、Raycast 规范，项目规范在 `../DESIGN.md`，原文和 MIT 许可在 `reference/awesome-design-md/`。
