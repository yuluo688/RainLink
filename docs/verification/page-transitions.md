# 页面切换动画 · 2026-10-16

侧栏和底部导航切换页面时，内容以 180 ms 淡入，从下方 8 逻辑像素回到原位，采用 `easeOutCubic`。桌面顶部状态栏、窗口控件和侧栏固定。全部九个内容路由共用这一过渡；设置页内部的分类切换保持现有行为。

过渡画布使用当前主题的背景色，避免上一页文字透出，内容裁剪在自身区域内。系统开启“减少动画”时立即显示新页面，路由过渡时长为零。

验证结果：

- Dart 格式、Flutter 静态分析通过。
- 23 项相关组件测试通过，包括快速连续切换后只保留最终页面、桌面导航和顶部位置稳定，以及桌面 / 移动布局下减少动画时立即完成切换。
- Windows x64 Release 构建与实际启动通过。默认紧凑窗口为 960 × 640，125% 缩放下客户区为 947.2 × 632.8 逻辑像素。
- 实际点击“概览 → 节点 → 设置 → 概览”，以约 30 fps 捕获窗口，确认淡入和位移生效。录屏按捕获时间播放，无变速；GIF 经过缩放和色彩压缩。
