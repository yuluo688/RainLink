# 移动标题区、首页与安全区域续验

2026-10-17。通过实时 Figma 读取移动首页 `2:22537`、设置 `2:23130`，参考位于 `reference/overview-mobile-current-20261017.png` 与 `reference/settings-mobile-current-20261017.png`。

## 修改

- 移除移动端额外的 RainLink 顶部应用栏；页面标题区保留导航入口，仍可进入规则、连接和日志。首页标题与设计一致使用 RainLink，五个 Tab 的第一个为首页。详情页继续使用左上角返回，不叠加导航按钮。
- 移动首页复用同一连接状态与操作，连接卡片使用紧凑排版。上传、下载与今日流量合并展示，不再把桌面质量卡片和延迟图纵向堆叠到手机首屏。延迟仍在连接卡片显示；详细流量曲线位于流量 Tab，桌面继续保留原有趋势和质量数据。
- 出口 IP 与国旗分行展示，支持选择复制。长 IPv6 自然换行，不再被国家列和刷新按钮挤成省略号；桌面正常宽度的出口排列保留。
- 移动页面边距与底部导航压缩，导航内容高度 56，系统底部安全区另计。内容通过 SafeArea 避让系统状态栏和手势区，触控区保留至少 44；字体没有缩小来适配屏幕。
- 窄屏与大字下，速度数值和完整单位各占一行，避免将 MB/s 拆成字母换行。

## 验证边界

组件回归验证 393×852 普通字号下，iOS 顶部 54 / 底部 34 和 Android 顶部 24 / 底部 24 的安全区域均不会挡住统计，首页滚动范围为 0。320×640、1.3 倍字号及完整长 IPv6 可以自然滚动，出口和统计仍可访问。另验证移除应用栏后规则、连接、日志及设置返回入口可用。

Windows 渲染器的 fixture 图覆盖 1440/960 桌面和 393/320 移动的深浅主题，主要页面位于 `ui-alignment/*-fixture.png`；设置另有 60 张图。移动 393 使用 iOS 布局及上述安全区，320 使用 Android 布局及上述安全区；系统状态栏内容由实际操作系统绘制，截图不伪造状态栏。测试 IP 为文档地址，节点和流量均是隔离样例。

以上证明共享布局与交互，不代表已在 iPhone 或 Android 真机完成网络连接。移动原生网络服务仍未接入，无法据此宣称全部 UI 与全部平台功能已完成。

Flutter 全量 244 项通过，最后排版调整后 11 项重点回归再次通过。原生渲染验收日志为 `build/mobile-final-visual.log`；大字 IPv6 与单位截图为 `ui-alignment/overview-mobile-320-large-*-fixture.png`。
