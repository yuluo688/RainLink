# 节点本地设置与独立测速

2026-10-16。产品继续保持桌面默认 960×640、移动独立布局；本轮完成节点收藏、订阅本地别名、隐藏恢复与可取消的独立测速。

## 操作与数据

- 点击星标收藏；分组下拉底部切换全部、仅收藏、已隐藏，仍可叠加分组与搜索。
- 订阅节点的「⋯ → 本地别名」仅改变本机显示，原名与地区继续保留，留空恢复订阅名；别名最多 128 字符，不接收控制字符。搜索兼容原名与别名。
- 「隐藏节点」清除后续选择与该组记忆，隐藏列表可以恢复。当前连接快照不受影响，已有规则、代理链的明确引用仍可工作；新增目标选择不提供隐藏节点。
- 手动节点可收藏，沿用编辑、删除与仅未分组可移动的权限；订阅连接参数继续由来源维护。
- schema 5 新增独立 NodeOverrides 表，迁移保留旧数据，开启外键并级联清理。订阅更新和排序变动保留相同稳定身份的覆盖；真实身份替换/删除则清理，避免套用到新节点。覆盖不增加连接 revision。

## 测速范围

工具栏测试当前筛选列表，节点菜单测试单个节点。最多 3 个并发、每批 2000 个，使用独立 `serve-test` 和临时核心，不修改正常连接、节点选择、代理模式或系统代理。测速值是通过该节点访问固定 HTTPS 204 测试站的耗时，不代表带宽。

单节点最多 8 秒，请求最多 5 秒；只接受 204，不跟随跳转。结果校对 ID 和 revision，取消后的迟到回执和旧修订结果不会覆盖新状态。取消失败仍保留可重试入口。不支持的原生平台保持禁用并提示尚未接入。

## 原生集成与真实机场

`windows-evidence.json` 来自真实 Windows Flutter 窗口、DPAPI 和 sing-box。测试数据库在内存中，代理和源站均为本机受控服务：

1. URL 导入带认证的 HTTP 节点，概览选择全局模式，点击开始连接。
2. 收藏、改别名、隐藏当前节点后，活动 sessionId 和代理端口保持相同，实际 payload 继续通过认证代理传输；恢复节点与选择不重新连接。
3. 两个独立测速返回真实回执，拒绝认证的节点明确失败；本机代理拒绝所有公网目标，因此不把此场景称为公网成功测试。
4. 挂起独立 CONNECT 后点击取消，确认测试端 socket 实际关闭，正常会话仍可传输；总计核对 4 次实际 payload。凭据落库为密文，不修改用户数据库，不请求系统代理。

`remote-hy2-diagnostic.json` 是经授权只读用户数据库、实际公网核心转发：3 个 HY2 节点中 2 个成功（1291 ms、702 ms），1 个超时；系统代理精确保持，测试核心全部清理。此前 `remote-probes.json`、`remote-vless-probes.json` 仍保留失败记录。结论为机场存在间歇性，不能据此承诺所有远程节点稳定可用。报告不包含服务器、订阅 URL、节点名称或认证。
