# Android 实时连接与日志验收

日期：2026-10-17。设备为隔离 Android 16 x86_64 模拟器 RainLink_QA，尚未覆盖真机和远程订阅。

AndroidCoreGateway 现在实现 CoreTelemetryGateway，复用桌面的共享 Controller、SQLite 日志仓库及界面。Android 端不再显示“当前平台尚不能读取核心连接”。

## 实现

- 连接使用原生已编译快照中的真实会话 ID、本机认证控制接口及实际出站名称。桌面与移动共用分页和关闭逻辑：每页最多 32 条，同一快照分页保持稳定；陈旧会话、过期快照和非法连接 ID 被拒绝。未知进程仍显示未知。
- Flutter 两种传输共用严格分页合并器，拒绝会话、快照、采样时间、总量或计数在分页中变化，以及重复 ID、空续页和循环游标。
- 连接页窄卡片按需缩放统计数值，完整保留数值和流量单位；393 普通字号、320 标准密度和较大字号的现有布局回归通过。
- 移动分组卡片的订阅用量与完整到期日期不再共用带省略号的长行，节点数量移到名称旁；小屏与大字允许自然换行，保持操作区域。
- 单条和全部关闭均由核心执行，并回读确认原连接 ID 消失；关闭请求不会断开系统隧道。应用自动重建的新请求可以再次出现。
- 服务持有公共脱敏日志缓冲；每个会话的写入器独立持有凭据过滤表，服务公共缓冲不持有凭据。临时测速不写入用户会话日志。
- 日志跨节点连接及 Activity 重建保留公共游标，断开后仍可读取和清空。Flutter 前台每两秒采集，SQLite 保留 7 天及最多 5,000 条。后台暂停 Flutter 采集，原生保留最多 2,000 条；溢出会报告缺失，未承诺后台无损持久化。
- 确认清空使用核心游标检查点，之后继续采集新事件，不重放旧记录。暂停页面仅冻结视图。

## 证据

[七项原生测试](android/instrumentation.txt)与[机器结果](android/native-evidence.json)包含独立 shell UID 经实际 TUN 保持的三条传输。服务端记录三次保持请求及三次关闭；单条关闭、全部关闭和关闭后继续传输均有断言。陈旧会话和 `../configs` 不能影响有效流。日志在断开后逐页读取，排除测试密码、用户名和密文，确认清空后没有旧事件。

[Flutter 实际界面结果](android/flutter-telemetry-evidence.json)单独使用本机 HTTP 目标，经显式本地代理和实际 libbox 传输：

1. 使用真实平台桥接、内存 SQLite 和带认证的测试节点连接，显示实际连接列表并筛选、暂停。
2. 在界面导出连接 CSV，检查新生成文件的实际内容，再点击关闭；等待真实响应流结束，并确认列表消失。
3. 断开后继续收集实际核心日志；在日志界面导出 CSV，检查凭据没有进入文件；确认清空后读取 SQLite 为空。

该测试证明 Flutter 到实际核心的操作路径，不能代替独立 UID 的 TUN 接管验收。实际截图为[连接](android/connections-real.png)和[日志](android/logs-real.png)，与 [14 张深浅主题视觉 fixture](android/ui/evidence.json)分别记录。

共享回归为 383 项 Flutter；宿主 Go 94 个通过测试事件、26 个跳过，移动模块 Android arm64 `go vet` 与 Flutter analyze 通过。新增移动适配器测试覆盖稳定分页、出站名称、未知进程、真实关闭回执、取消、共享日志及会话凭据隔离；Android 平台测试覆盖分页变更、重复 ID、关闭失败、空闲日志、释放界面和系统文件保存契约。

## 范围

正常 Android 应用通过系统文件保存器导出 CSV，由用户选择位置。Flutter 界面测试显式使用应用私有 `exports` 目录检查内容；原生测试独立完成真实系统选择器的保存、读回、取消及生命周期验收，见[系统文件保存](android-documents.md)。系统分享入口尚未实现。日志进程归属取决于核心实际可提供的数据，不根据域名猜测应用。

正常开发预览为 `build/RainLink-0.1.0+3-android-debug-preview.apk`。先运行界面测试，再重建 `lib/main.dart`、重跑原生测试和完整 APK 检查，确保最终包不是集成测试入口。最新包和原生机器记录中的 SHA 必须一致。
