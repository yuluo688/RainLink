# 订阅兼容确认与详情校准

日期：2026-10-17。版本：0.1.0+4。此阶段完成共享订阅解析、部分兼容内容确认、兼容原因持久化及相关弹窗的双端校准；全产品和其余平台的进度仍见[实现清单](../IMPLEMENTATION_STATUS.md)。机器证据为 [evidence.json](subscription-compatibility/evidence.json)。

## 使用方式

在「节点 → 添加 → 订阅」或「分组 → 添加订阅」粘贴 URL。名称由服务商或来源自动识别，订阅自动成为一个分组。全部兼容时直接导入；包含不兼容节点或其他全局配置时，在原弹窗显示可导入数量和原因，点击「确认导入」才保存。默认显示三项原因，展开后使用受限高度列表。

手动更新出现兼容变化时，在原订阅详情中点击「确认更新」。关闭弹窗保留上次可用节点；自动更新不会静默接受部分内容，会保留旧数据并显示需要确认的更新结果。再次手动更新可查看当次预览。服务商的本机提示条目单独标注，不作为可连接节点；只有提示条目而没有真实节点时拒绝导入。

兼容预览只保存在内存，有效期十分钟。确认提交同一份内容，不会重新下载。修改 URL、切换添加类型、关闭弹窗或取消会放弃当前预览；伪造、重复、同时确认、过期、组已修改或删除的预览都不能重复写入。无任何可用节点时只展示失败明细，没有「确认导入 / 更新」入口。

未连接时订阅直连下载；已连接时通过当前 RainLink 本地代理，遵循活动模式和规则。下载开始时读取一次本地端点，重定向继续使用它。连接正在切换或已连接但端点无效时明确失败；代理失败不会自动回退直连。连接变化不会重新创建订阅仓库，因此已展示的兼容预览不会被清掉。没有新增设置或页面。

## 格式与边界

| 来源 | 范围 |
| --- | --- |
| Clash YAML / JSON | `proxies` 节点，按协议校验字段和嵌套传输参数 |
| sing-box JSON | `outbounds` 中 HTTP、SOCKS5、Shadowsocks、VLESS、VMess、Trojan、Hysteria2、TUIC v5 的兼容节点 |
| 明文 / Base64 列表 | 已支持的分享链接，校验协议参数、别名冲突及布尔值 |
| 远端完整配置 | 只导入节点；规则、DNS、监听、脚本及 provider 等配置列出说明，不直接应用 |
| 未接入参数 | 策略出站、内置行为、detour、拨号覆盖、复用及不支持的 TLS / 传输字段明确说明，不静默改变连接语义 |

sing-box 字段映射对照锁定的 v1.12.25 源码及实际宿主配置；支持格式不等于所有服务商组合都已完成远程验收。Hysteria 1、TUIC v4 仍未接入。错误使用条目序号和安全原因，不保存订阅地址、节点名称、URI 或认证到兼容原因中。

schema 7 为分组增加兼容信息列。已有节点、选择、凭据和本地覆盖继续保留；已确认的更新复用原事务与身份匹配逻辑。需要确认、获取失败或全量无效时，仅记录尝试时间与安全错误，不覆盖上次成功的节点和套餐元数据。

真实远程证据分开保留，不用本地夹具代替：

- [remote-evidence.json](subscription-compatibility/remote-evidence.json)：授权的两个 HTTP 节点直接连接超时，通过 RainLink 启动真实核心后 HTTPS 握手失败；这批直连订阅获取失败，因此没有新导入 HY2。系统代理精确保持，测试监听全部关闭。
- [remote-hy2-probes.json](subscription-compatibility/remote-hy2-probes.json)：只读本机已保存的三个 HY2 节点，使用隔离真实核心请求 HTTPS 测速站，全部成功，约 576 / 1439 / 826 ms；revision 匹配，测试核心清理，系统代理精确保持。此结果不证明前一批订阅地址及 HTTP 节点已恢复，也不代表全部远端节点长期稳定。
- [subscription-via-hy2.json](subscription-compatibility/subscription-via-hy2.json)：使用独立宿主的 HY2 会话、不启用系统接管，订阅返回 HTTP 200 / 517,317 字节；真实 Dart 生产下载器再次通过同一本地代理获取并解析 68 个兼容节点（52 VLESS、16 HY2），用量 / 总量 / 到期均存在。两项未导入、十一项兼容原因，需在产品弹窗确认。此工具只读既有密文来源，未保存响应和新节点，没有代用户确认真实订阅更新；宿主和监听清理，系统代理精确保持。

测试期间保持 FlClash 关闭，未操作其服务或用户手机。报告不包含真实订阅 URL、节点名称、服务器和认证。订阅直连与经 HY2 的结果明确分开；HTTP 节点失败原因仍待服务商和网络条件进一步核实，没有据此判定账号过期。

经授权复验现有订阅，可运行 `python tools/verify_subscription_path.py --dart <Dart 可执行文件> --output <报告路径>`。URL 与密文从只读数据库读取，经私有 stdin 交给宿主和 Dart，不接受明文凭据 argv；未传 `--dart` 时仅核对传输，不代表解析 / 导入通过。
