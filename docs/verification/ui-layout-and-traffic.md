# 界面还原与真实统计验证

日期：2026-10-16。对应 `RainLink-windows-x64-ui-aligned-preview.zip`。

## 差距来源与改动

本轮通过 Figma MCP Bridge 读取当前 RainLink 文件，概览节点 `2:17066`、流量节点 `2:19136`。参考截图为 [实时概览](ui-current-figma-overview.png) 和 [实时流量](ui-current-figma-traffic.png)。Figma 使用 1440 × 900；默认软件窗口另需适配 960 × 640。

之前的功能骨架没有完整落实页面结构：概览将连接与控制左右排列，又把出口塞入统计行，缺少节点健康区域；分组连成一张表，流量仍是占位页。另一个共同原因是 Flutter 桌面默认的 compact 控件密度，把设置为 40 的按钮缩到 32。仅导入 SVG 和颜色不能修复这些布局偏差。

本轮实现：

- 概览恢复连接主卡、网络控制、独立出口、三项统计、趋势与节点健康的层级。1440 窗口按纵向布局，紧凑窗口将系统代理 / TUN 与模式选择并排，其余层级保持一致。普通文字下完整一屏；大字号和窄屏仍可滚动。
- 连接主卡使用实际分组与节点；活动快照的节点被删除后，不会错误显示新选择的分组。已连接状态采用品牌表层。
- 校正页面标题间距、侧栏品牌与导航位置、顶部目标和实时速度顺序，固定标准控件密度。继续使用已有 Figma 原生 SVG、国家图标及本地字体。
- 分组使用独立圆角卡片，桌面分别显示数量 / 自动更新、真实订阅用量进度和到期信息。仅点击选择；右侧「节点」浏览该组。移动端维持紧凑列表，无节点名字展开。
- 节点收紧行高，增加协议标签、明确的选中边框；延迟仅展示活动节点的真实请求探测结果，其余写「未探测」。批量测速仍未接入。
- 流量页显示真实总量 / 下载 / 上传、今日 / 本周 / 本月切换。今日曲线为当前会话最多 60 次实时速度采样；本周 / 本月展示每日用量，不伪造历史速度或应用排行。移动端明细独立换行。

## 统计存储与验证

`TrafficRepository` 新增按日历史读取。SQLite 的既有 Preferences 表保存 `traffic.day.YYYY-MM-DD`；保留旧 `traffic.daily` 会话计数检查点，首次写入时在同一事务中迁移最后一天。无需修改数据库表结构，schema 仍为 3。旧数据及新日期不会重复相加；更早已经丢失的历史不会补造。

计数保存差值，重复 / 迟到的观察不会重复计费；非法负数在写入前拒绝。午夜会更新今日统计，订阅和定时器随消费者取消释放。周从周一开始，月从每月一日开始，日期按本机日历计算。

验证结果：

- 全量 Flutter 单元 / 组件测试 **124 项通过**，静态分析无问题，Dart 格式检查通过。
- 新增旧统计迁移、跨日保留、重建仓库、重复 / 迟到计数、非法输入、周 / 月 / 闰日边界和 60 次采样上限回归测试。
- 1440 × 900、960 × 640、892 × 632 的已填充深浅主题布局检查通过；概览无滚动，主卡与出口左右对齐，趋势与健康上下对齐。
- Android 布局在 393 × 852、320 × 640 的已填充节点 / 分组 / 流量组件测试通过。未在 Android / iOS 设备运行本轮构建。
- Windows 原生 Flutter 渲染测试通过，生成 14 张截图；截图覆盖两种桌面尺寸、概览 / 流量深浅主题，以及节点 / 分组 / 设置深色。渲染测试使用隔离 fixtures，不访问用户数据库、不启动网络连接、不改变用户主题设置。
- Release 构建、引擎 SHA-256、真实启动和归档检查见 [构建记录](ui-alignment-build.json)。

## 尚未覆盖

此次修复的是概览、节点、分组与流量的主要结构和共用控件。设置中的开机启动 / 托盘 / 通知等行为，以及可编辑规则、连接明细、日志、代理链执行、TUN、VMess / Hysteria2 / TUIC 和移动端网络接管仍未完成。UI 仍有这些功能和页面内容缺口，不能据此称全部页面已按 Figma 完整交付。

网络质量区域使用实际请求耗时，不生成没有测量依据的 98/100 或丢包率；节点健康不把未测试节点标为在线；用量明细按日显示，不冒充进程排行。本轮没有重复机场 / HTTP 服务商连接测试，上轮成功与失败记录继续保留在 [真实服务商验证](windows-real-providers.md)。
