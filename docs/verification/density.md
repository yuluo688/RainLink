# 界面密度与双端列表续验 · 2026-10-17

入口为「设置 → 外观 → 界面密度」，提供「紧凑 / 标准」。桌面仍默认 960×640 小窗口及紧凑布局；切换改变间距，不改变字号、导航平台、节点选择或连接参数。原有设置缺少密度字段时沿用紧凑；已存在的非法值明确报错，不静默重置。复用 `appearance.preferences`，数据库仍为 schema 6。

## 交互与尺寸

通过 `RainlinkDensity` 语义间距统一页面、列表、卡片、按钮、输入、分段选择及设置行。深浅主题分别缓存两种密度，切换不重建连接会话。节点行紧凑 56、标准 64；桌面密度选择器紧凑 36、标准 40，手机至少 44，收藏与菜单保留 44 点击区。字号放大时允许必要增长，避免压字。

保存完成后才采用新密度，写入失败保留原布局和选项，可直接重试。外观选择器使用受控状态，修复了 `DropdownButtonFormField` 内部草稿在失败后仍显示新值的问题；字号选择也使用同一组件。手机正常宽度时标签和 148 宽选择器并排，窄屏及大字改为上下排列。

标准模式的小桌面概览增加连接卡的必要高度，避免两行操作溢出，普通字号下概览仍一页显示。320 宽大字的添加弹窗允许协议选择器收缩，避免最长协议项撑出边界。手机连接、日志不再压缩桌面多列表格，分别采用三层连接项和两层事件项；列表仍为有界虚拟列表，页面可滚动访问工具栏与数据。搜索、暂停、导出、关闭/清空和日志跟随保留。
