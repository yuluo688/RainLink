# 持久流量、归属与 CSV

2026-10-16。本轮完成持久用量曲线、保守归属排行、日/周/月 CSV，并校正两端布局。

## 记录规则

SQLite schema 6 增加 TrafficBuckets、TrafficSources、TrafficCheckpoints。每次实际观测在一个事务提交日汇总、15 分钟用量、归属及该会话的累计检查点；每会话独立去重，重新打开、交错迟到样本、重复计数和时钟回退不会重复累加。旧日汇总与最后会话检查点在首次写入时迁移，不为旧数据生成时段曲线或节点归属。

图表今日显示每 15 分钟的字节用量，本周/本月显示每日字节用量。它不是带宽或每秒速率图；无记录时段留空，实际观测的零用量保留。应用在前台且连接时每 2 秒采样，离开概览后继续记录；后台与休眠暂停 UI 轮询，恢复时把新增计数记入当前时段，不推测间隔内真实分布。日期按观测时本机民用时间记账，时区改变不会重分配已有日记录。

详细时段保留 400 天，日汇总与会话检查点继续保留。页面按所选周期查询，避免每次采样读取全部时段历史。

## 归属边界

持续保持初始全局模式的会话可以归属主节点/代理链，持续直连的会话归属直连。规则模式可能同时使用多个出站，因此记为「未归属流量」。在线切换模式后，已有连接可能继续用旧路由，当前会话后续增量均记为未归属，直到下次新建会话。旧版记录也计入未归属，排行总计与周期用量守恒。

未提供可靠进程归属，也没有把规则流量冒充成当前所选节点的流量；进程与规则多出站的精确统计仍在后续范围。

## 导出与布局

导出冻结点击时的当前周期，CSV 使用 UTF-8 BOM、CRLF、完整引号转义及公式文本保护，分别列出日汇总、时段明细、周期归属；三类行不能相加后当成额外总量。取消保存不会提示成功，文件错误保留界面并提示失败。复用已有原生保存服务，移动平台沿用应用文档目录。

实时读取 Figma 桌面 `2:19136`、移动 `2:23007`，原始参考为 `reference/traffic-current.png`、`reference/traffic-mobile-current.png`。桌面三张汇总卡、趋势及排行保留设计层级，960×640 一屏适配；移动汇总合并为一张卡片，导出用紧凑图标。图表悬停/点选显示实际数据，缺失时段明确为无记录。曲线单位采用真实持久字节用量，未把示例设计的 MB/s 沿用为错误单位。图标继续使用已原生导出的 Figma SVG。
