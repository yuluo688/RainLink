# 节点地区标识与列表校准

日期：2026-10-16。

通过 Figma MCP Bridge 重新读取「桌面端 / 节点」`2:17478`，参考为 [当前 Figma 截图](ui-current-figma-nodes.png)。设计使用独立的地区代码圆角标识，原实现直接渲染订阅名称内的旗帜 emoji，在 Windows 上成为小号区域字母，且缺少地区标识及辅助文字。

本轮修正：

- 地区标识为 28 × 28、圆角 9；与名称间隔 12。名称 14 / 20，辅助信息 11 / 16，普通字号下行高 56，与当前 Figma 节点行一致。
- 将订阅名称中的旗帜字符转换为独立地区标识，显示名称保留其余文字。支持旗帜前后无空格、括号包裹及末尾旗帜。没有旗帜时只识别明确的国家、地区代码或城市标签；未知地区使用已有 Figma 地球 SVG。
- 桌面第二行显示节点标注地区及名称中明确出现的城市；未知地区显示服务器地址。悬停名称可查看原始名称及服务器端口。移动端将协议与地区合并到第二行，避免窄屏时挤占名称。
- 桌面表头与行内容共用列比例；名称列获得更多空间，紧凑窗口保留 Shadowsocks 完整协议标签。菜单与选中标记分别预留位置，选中时菜单不再跳动。选中边框改为前景绘制，避免被背景遮盖。
- 搜索保留原名称、服务器、协议及分组匹配，并增加标注地区和地区代码；多个关键词取交集。概览与顶部状态栏同步清理旗帜字形，使用相同的显示转换。

显示转换不写回数据库，不修改订阅源名称、连接快照、节点标识、凭据或订阅刷新逻辑。地区代码与中文名称只是节点标签；真实出口仍只使用核心检测结果。当前中文国家 / 城市别名覆盖常用地区，其他明确旗帜保留地区代码；没有明确标签时不根据服务器域名猜测。
